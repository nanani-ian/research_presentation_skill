# Excel底稿｜分表与单表版式选择



用于M08建立或整理底稿，或M03准备Excel母图时。先选择工作表的内容归属，再决定同表各区如何排列；工作表、数据组、表格、图表和PPT页面之间不是一一对应关系。



## 先判断是否应放在同一sheet



**研究型汇报优先考虑按章节、公司、领域或指标主题组织，同一sheet可以有多组数据、表格、测算、说明、截图和原生图表。** 一图一sheet适合某些任务，但不是默认格式；数据量大也不直接推出必须一图一sheet。



| 情况 | 优先考虑的组织 | 何时进一步拆分 |
|---|---|---|
| 同属一个研究问题、章节、公司或业务领域 | 按内容分sheet，在同表分成多个模块 | 主题边界、表头宽度或维护方式明显不同，查找和修改已困难 |
| 多张相关图共用原数或相互解释 | 同sheet放两图、多图或多组表格，必要时共用一个数据区 | 长历史需要单独维护，或共用数据被多处重复复制 |
| 各图主题独立、字段与更新规则不同 | 图表单元式：一sheet一张图或一组紧密相关图，带原数、作图计算及说明 | 不因独立图表较多反向合并无关内容；用目录导航即可 |
| 大量日频或月频数据被多图、多页共用 | 原始数据区或原始数据sheet统一维护，计算与专题作图区按需分开 | 源数据行列很多、增量更新容易挤占展示区，或独立来源需保护 |
| 市场空间或预测需要多步推导 | 按业务或领域保留假设、过程、汇总结果；同表多组计算自然衔接 | 有多个领域或大体量共享输入，再拆输入或汇总，不为每个中间结果新建表 |
| 主要为技术说明、政策、竞争格局等资料 | 同表组织说明表、分类表、来源截图和必要图表 | 内容跨主题或宽度失衡时按专题拆；不强制每表生成数据图 |


分表依据包括内容联系、数据规模与增长、共用程度、更新频率、字段兼容、查找与交付习惯。先沿用已有底稿的有效结构；没有依据时不新增固定数量的表，不按PPT页码强行拆表。



## 同一sheet的四种可选版式



### 1. 模块向下展开，每模块横向配套



适合公司分析、章节研究、分领域测算。顶部简短主题或模块索引；下方按论证顺序排“模块A、模块B、模块C”。每模块内部可采用“图在左、数据在右”“原文在左、整理表在右”或“说明与原数在上、结果图在下”。



每模块用简短标题、轻底色或留白分开；相关图表、来源与数据保持近邻。不同模块有不同期间、单位或字段时各设表头，不能只为对齐而混用口径。同一模块若共用同一日期轴和指标表，可统一维护表头，避免重复输入。



例：海外镍企的ANTAM产销量sheet含年度、季度产销量及经营指标，合计6张原生图表；汽车领域sheet先放应用场景，再放测算模型、具体计算与来源证据。借鉴的是内容分块，不照搬它们的列宽、超长空白或全部截图。



### 2. 上方展示图，下方数据与计算



适合周报、周期跟踪、相关指标并列。顶部只留主题、来源、单位、绘图窗口与必要说明；中部放一张或多张图；下方保留完整原始数据与作图数据。



多图可两列并排或2×2排列，依据关系和可读性决定，不把每张相关图强拆成sheet。长数据在下方追加；完整历史与当前展示窗口分开维护，缩短绘图区间不删除原始历史。



例：镍周报的01 NI2612收盘走势在顶部说明之后放图，数据表从第28行开始；18 无锡佛山300系库存同表两图，19 两地300系冷热库存同表四图，后两者数据从第45行开始。这些行号仅解释样本结构，不是新底稿固定行号。



### 3. 左侧原数，右侧整理与结果



适合口径转换、跨公司比较、成本结构、历史与预测对照。左侧保留原始字段及原单位，右侧经空白列分隔后放统一口径、公式、对比表和图表；需要时把相关原文截图放在不遮挡数据的位置。



不要无限横向扩展造成频繁缩放。不同表格列宽不兼容时可改为向下分模块。数据表不为“展示效果”合并实质字段；展示分组标题可有适量合并，不阻碍筛选和公式扩展。



例：晶圆代工按制程、利用率、成本分sheet；中芯成本sheet中可有金额与比例、折旧等多组表。光刻胶按市场规模、技术参数等专题，把文字表、数据与图片结合。



### 4. 数据维护与展示分层的混合结构



适合长期更新的大数据工作簿。原始历史按真实业务或来源统一维护；计算区完成换算、筛选、同比、季节性对齐等；作图区按主题集中多张图，汇总区只引用已完成结果。



“分层”可以是同一sheet的不同区域，也可以是不同sheet；不用强制各建一张输入、计算、输出、来源和检查表。共享数据计算一次，多图引用；不为迁就一图一sheet而复制相同历史序列。



例：不锈钢需求汇总包含数据、汇总、作图相关工作表；缅甸稀土与算力则主要按研究框架或章节，把多个证据、表和图放在同sheet。两类可以结合使用。



## 同表多模块的实际排版要求



- 主标题、模块标题和正文形成少量层级；正文常见10—11磅，按字体与内容调整。说明用普通单元格，不写大段装饰性副标题。

- 同类模块左边界、表头层级、图表尺寸和间距尽量一致；标题用适度底色或边框区分，不把每个单元格都加重边框。

- 图、表、说明与来源有明确对应，不把所有来源集中为无法追到数据的机构清单。多个来源可在数据旁对应行列记录。

- 同表可有多套日期、单位与表头，分别标清。仅在确实共用相同期间和含义时共享表头，不能强行把不同频率对齐成同一序列。

- 图表不得遮挡原数、公式或输入；留出历史追加空间。图表浮动位置、冻结区域和打印范围按实际查看与更新方式设置，不默认冻结大块空白展示区。

- 数据表保持可计算，说明与截图不打断记录结构。原数、预测假设、计算结果与作图数据可分区区分，但不要重复维护同一个数字。

- 共用数据的多图分别保留图表编号与引用范围；PPT可以从同一sheet选取多图，也可以多页共用一组数据。页序调整不要求重构Excel。

- 同表过长时先增加简短模块索引或内部跳转，再考虑按真实主题拆分；不仅因为图多就拆。同表过宽时先调整排列方向，不先把字体缩小。

## 开工与验收



先用一句话说明采用“按什么分sheet＋同表怎样分区”，再执行已授权工作，不要求用户额外批准常规选择。复杂布局需要比较时提供少量方案或局部预览，不先做完整底稿再讨论。



验收看内容归属和维护是否方便：同一问题能找到完整材料，多图对应的数据清楚，追加数据不挤乱版面，没有无必要重复历史或过多空表。沿用M08的数据、来源、原生图表及PPT连接要求；不能只看sheet数量或“一图一表”是否整齐。


## 可直接复用的Excel模板

下面四份是实际可打开、可编辑的`.xlsx`，并非截图。按任务选一份复制后使用，无须全部复制，也不强制把研究型底稿改成一图一sheet。

| 模板 | 实际结构 | 优先使用的情况 |
|---|---|---|
| [01 章节公司多模块](../assets/workpapers/01_章节公司多模块.xlsx) | 一张主体页内纵向放产销量、收入成本、定性证据三个模块；两张原生图就近配套 | 公司研究、行业章节、案例或政策专题，同表需容纳多组数据和资料 |
| [02 周期跟踪上图下数](../assets/workpapers/02_周期跟踪上图下数.xlsx) | 同表上方两图，下方完整历史、变化公式和当前绘图窗口；两图共用期间 | 周报、月报、价格／库存等周期跟踪；可按关系扩展为四图 |
| [03 分领域驱动测算](../assets/workpapers/03_分领域驱动测算.xlsx) | 一领域页内放原数与假设、单位换算、需求与增速公式、假设依据和一张结果图 | 市场空间、分领域需求或驱动模型；不按每个变量拆表 |
| [04 共享数据与专题作图区](../assets/workpapers/04_共享数据与专题作图区.xlsx) | 两张表：共享历史保留原数及换算，专题作图区用跨表公式引用并画两图 | 多图、多页共用历史；长期更新、原数较多或需要集中维护 |

**直接使用**：按研究问题选结构 → 另存项目副本 → 替换演示数字和来源 → 调整图表及公式范围 → 核对结果、单位和可读性。只有独立主题确实适合时，才使用一图一sheet；也可在一份底稿中混用这些组织方式。

模板中浅黄底蓝字为可改输入，浅紫底深字为公式结果，全部数字明确为演示，不代表原样本、真实公司或预测。演示公式仅说明计算关系，不能替代研究依据。紫色图表和楷体图题用于演示；新项目仍以主PPT模板与用户指定的图表规范为准，不固定沿用长鑫风格。

每份模板已留来源位置、稳定图表编号、当前PPT页码、数据／计算范围、母图位置和更新说明。页码未定时留“待填”；不要为套模板虚构机构或文件。真实项目的来源可以保留更详细的链接、日期、原文定位和截图，PPT仅列所需简短出处。

图表均以工作表单元格为数据源，包含7张Excel原生图表；输入和公式均可编辑。本模板库没有PPT文件、外部数据连接或PPT链接。预览可从实际Excel母图导出；只有获准进入M05后才建立PPT连接并按M08实测刷新。新增行列不会自动扩展固定图表范围，更新时须同时检查公式与图表引用。

这些轻量资产按用户提供的八份底稿的组织方式归纳新建，没有复制或改写原始工作簿，也不包含其真实数据。模板用于复用结构与工作方法，不承诺像素级复刻任何一个样本。
