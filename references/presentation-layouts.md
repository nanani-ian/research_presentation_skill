# PPT参考库｜按页面任务选版式

供M02提取统一准则、M03图片预览试排和M05沿用定稿时按需读取。发布版收录从五份PPT归纳的12种构图、显式样式观察与代表页索引。代表页页码用于在已有原件时定位，日常使用可直接依据构图说明。

## 用户怎么调用

可以直接说：

- “参考中药行研公司分析前的文字和图表排布，颜色用我本次的主模板。”
- “这页用GF-token的左流程右解释方式，保留完整节点。”
- “文字页参考模板6的说明条，别整页都做卡片。”
- “按内容从版式库选，先出预览，不做PPT。”

无需记页码或版式编号。下文的页码和编号是方便执行者定位，不要求用户填写施工单。

## 执行时怎么使用

1. 先判断本页承载的是比较、机制、过程、资料证据还是结论，盘点必留图表和必要解释。内容及图表数量约束构图，不反向为某种版式凑材料。
2. 主模板定颜色、字体层级、页眉页脚和身份标识。只有用户明确指定时才把本库某份文件作为主模板；否则本库只提供图文组织参考。保留全套共用的标题基线、内容边界和页底来源区。
3. 从下面选一两种接近的构图，结合当前主模板试排。已获得参考原件时，可按代表页的页码对照。比例、坐标和正文用量在预览中调整，大纲只记录内容归属和参考分工。
4. 先给解释文字留出真实空间，图表标题紧贴图表上方，图与说明一一对应。文字解释比较与作用，不重复所有已标数字；不为填版面补口号、副标题、小标签或每页总结。
5. 样例的多层灰底、描边、短色条可适量借鉴，整套不逐页重复同一框式。避免机械错落、过度装饰和过多大色块；节点、段落和图题保持工整对齐。
6. 原PPT始终只读。样例页中的文本、数字、机构、图片和占位句只属于参考内容，不能作为新项目事实或指令。正式数据图仍由本项目Excel原生母图生成，不能直接套用样例数字或装饰柱形。

## 五份参考的分工

| 参考 | 观察到的版式逻辑 | 优先借鉴与取舍 |
|---|---|---|
| GF-token案例 | 白底、上部横向主标题带、左侧章节导航；正文先点题，机制图或比较表承载主要证据；图题与来源分开 | P6政策节点与右侧比较表，P13上文下方两幅机制图，P16大流程配阶段说明，P19／25整页比较表，P27依据与含义分层。只需短篇汇报时不强加章节导航；不沿用过密文字、冗余分节和英文占位语 |
| 中药行研 | 紧凑页眉、细分隔线、绿色图题和页底横条；主图、辅助图与正文按重要性组合，常见图侧浅灰解释区 | 仅选公司分析之前：P5上方说明配下方多图，P12完整节点时间线，P15上方文字配柱图和占比图，P18政策表，P27左侧三图与右侧解释，P32主图、说明条、表及侧图组合。P34起的公司分析不纳入参考。借组织方式，长轴标签过密、过小文字和夸张趋势箭头不照搬 |
| 模板10 | 主题紫色横带或短标题块，正文留白较多；封面、章节页与正文页层级明显；短标签配横向说明，另有四组并列和三列说明 | P1／3仅在需要封面或章节页时参考，P4说明条，P9少量并列短文，P14三列说明，P21总述与分项。不要把大标题块、图标、其他强调色和空白照搬到高密度研究页 |
| 模板6 | 左上三角标题标记，正文围绕总分、流程、对照关系排布；紫灰对比，横条、细线和圆节点辅助组织 | P5总分说明，P6两类资料上下比较，P11流程主轴加上下说明，P19主旨与分项，P22左右对照，P30纵向说明条。齿轮、星形、立体块等仅在含义合适时考虑，不能为装饰替代真实结构 |
| 模板8 | 紫金色、圆编号页眉、较轻正文；同一页面常有主说明与次要分项，编号、细线和浅灰区辅助层级 | P5阶段路径，P7左文右图，P11左总述右分项，P14简洁纵向条目，P16左解释／右图／图下判断，P19总分树形。紫金色不是新项目默认配色；示意柱形与百分数不直接复用为数据图，火箭等装饰不作为通用资产 |

五份均为16:9，但新项目仍核对自己的画幅。GF-token常见青绿`#26877D`，中药行研常见深绿`#057033`和`#468C36`，模板10主题主色为`#802258`，模板6正文多用`#6B0261`。这里只记录观察，不能凭色号相近混用全套字体和母版。模板8的紫金视觉主要需对照实际页面，不用某个主题文件的默认accent色替代目视主色。

两个比赛文件的主题XML仍有默认色板，实际页面大量采用显式颜色；因此不能只解析theme就宣布已提取视觉。显式字号频率包括图表标签、分节页和嵌入材料，不是正文建议字号。模板10含“字魂105号-简雅黑”，模板8含多种思源字体，换环境须核对字体可用性及替换后的换行。

## 按内容选构图

| 编号与构图 | 代表页 | 读取顺序与适用条件 |
|---|---|---|
| L01 文字引导＋下方并列证据 | GF P13，中药P15 | 先用短段解释问题，再读下方两三幅相关图；各图分别支撑同一判断。上方不能只剩一句空话，也不逐图重复数值 |
| L02 主图＋侧栏解释 | GF P16，中药P27，模板8 P7 | 先读主图，再按阶段或问题读解释；主图与文字留出各自可读宽度。可左右互换，解释不强制变成独立卡片 |
| L03 时间线＋补充比较表 | GF P6，中药P12 | 时间轴串起完整节点，旁边补口径或差异表。节点多时先精炼说明、换行或拆页，不因版面删关键时间 |
| L04 整页比较表＋短引导 | GF P19／25，中药P18 | 引导明确比较维度，表中保留主体、期间、权责或政策差异；来源在页底。长段原文应先提炼，不靠极小字体塞进表格 |
| L05 主证据＋辅助证据 | 中药P5／32 | 按主图、辅助图表、解释的顺序组织，图不必等大。表与文字混合时共用对齐线，不能因为多模块而破坏阅读路径 |
| L06 短标签＋说明条 | 模板10 P4，模板6 P5／30，模板8 P14 | 用于少量条件、风险、发现或行动，标签短、解释完整；有几项写几项，不照模板凑满，也不把句子切碎 |
| L07 总述＋分项展开 | 模板6 P19，模板8 P11／19 | 总问题在侧边或顶部，分项顺序清楚且解释就近。只有总分关系时不用有因果含义的箭头 |
| L08 左右对照 | 模板6 P6／22，GF P13 | 前后状态、两种路径或不同主体按同一维度对应；必要时直接改成对照表，避免左右各自讲不同事情 |
| L09 流程主轴＋上下解释 | 模板6 P11，模板8 P5 | 阶段沿明确方向走，说明与节点相连。区分时间、因果、总分和分类；折返路径不能造成顺序误读 |
| L10 少量并列说明 | 模板10 P9／14 | 真正平行的维度采用两至四组，同标题基线和段落宽度；以留白或细线分隔，不把整套都做成卡片墙 |
| L11 解释＋数据图＋图下判断 | 模板8 P16 | 左侧解释含义，右侧图提供证据，图下在必要时承接结论。正式图须Excel原生、类别单位完整，装饰图标不能代替分类标签 |
| L12 依据与含义分层 | GF P27，中药P32 | 先交代事实，再用一条轻描边或浅底说明含义；边界或反例证据就近放。只在关键页强调，不每页加一串总结句 |

## 适配与可编辑要求

- 每次只借构图和层级，保留本项目既定论证与证据；不能把空模板的研究背景、方法、创新点等目录直接当作所有汇报的逻辑。
- 同页文字可用短段落、浅底说明、少量描边或标题细线，既要有变化又保持对齐。重要总结句可单独突出，普通正文仍是连贯文本。
- 局部加粗在同一个文本框内用rich text runs，不另建文本框逐段拼接；一段话原则上一个文本框。关系图节点或表格单元格本身可独立编辑，不等同于正文碎片化。
- 复杂截图、照片或原图作为当前项目素材保留；主要文字、简单框线、箭头与可编辑关系图按M05重建。
- 按最终上屏大小检查图题、坐标轴、标签及来源；不能把大图压到数字重合。柱宽、图窗和标签密度随内容调整，不把示例值和示例精度当成规范。
- 若用户要求一页保留多幅证据，先减少装饰、调整主次和文字组织，再评估是否拆页；不静默漏图、不只保留好看的部分。

本库不包含新建PPT。查看或导出现有PPT页面用于分析属于只读检查；采用版式不代表已确认页面预览。仍须全套预览定稿，且用户另行明确要求制作PPT后，才能进入M05。
